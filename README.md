# Inventory Management System

A web-based application for organizing, tracking, and managing product inventory in one place.

## 🛠️ Built With

- PHP
- JavaScript
- HTML
- CSS

## ✨ Features

- Add, view, edit, and delete products
- Manage product categories
- Track product quantities and stock levels
- Search and filter inventory records
- Monitor low-stock products
- Responsive user interface

## ⚙️ How to Run Locally

Follow these steps to run the project on your local machine.

### Prerequisites

Make sure you have PHP installed on your system.

- [Download PHP](https://www.php.net/downloads.php)

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Navigate to the Project Folder

```bash
cd YOUR-REPOSITORY
```

### 3. Start the PHP Development Server

Run the following command inside the project folder:

```bash
php -S localhost:8000
```

### 4. Open the Application

Open your browser and visit:

```text
http://localhost:8000
```

The application should now be running locally.
